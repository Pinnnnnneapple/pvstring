# Reproducible illustrative examples

Every equipment value and climate record here is synthetic/generic. These
are calculation examples, not installation designs.

| Example | Array | Expected result |
| --- | --- | --- |
| `residential/passing-array.json` | 8 modules/string, strings/MPPT 1,1 | PASS, exit 0 |
| `residential/failing-array.json` | 16 modules/string, strings/MPPT 1,1 | Cold inverter over-voltage and other failures, exit 2 |
| `commercial_1500v/passing-array.json` | 22 modules/string, one string on each of 10 MPPTs | PASS, exit 0 |

The residential temperatures are −18 °C / 33 °C; the commercial temperatures
are −18 °C / 35 °C with a rear/front irradiance ratio of 0.15. Neither site
claims a measured station or actual ASHRAE design record.

Generate the residential reports from the repository root:

```sh
pvstring check --module examples/residential/module.json \
  --inverter examples/residential/inverter.json \
  --site examples/residential/site.json \
  --array examples/residential/passing-array.json \
  --html examples/output/residential-pass.html \
  --json examples/output/residential-pass.json \
  --md examples/output/residential-pass.md
```

For the failure report use `failing-array.json` and `residential-fail.*` output
names; the nonzero exit is intentional. For commercial outputs use the files
in `commercial_1500v/` and `commercial-1500v-pass.*` output names. Reports in
`output/` are generated by the CLI, not hand-edited. Each `*.txt` file captures
the corresponding real terminal output. Open any HTML file directly in a
browser; its charts, styles, and print layout require no network connection.
